# Продуктивність працівників (звіти LEA від David Yurii)

Щоранку з `yurii.david@fintyre.it` приходить лист із вкладенням
`Produttivita_Operatori_61_<дата>.html` (HTML, не XML) — звіт LEA за один день.
Код розбору: `atlas/productivity.py`, тести: `tests/test_productivity.py`.

## Вкладки в таблиці «Atlas — пам'ять»

| Вкладка | Що в ній |
|---|---|
| `Продуктивність працівників` (sheetId 700001) | Тільки формули. B2 — вибір дня (список з дат у «дні»), рядок 6 — підсумки дня, з рядка 9 — працівники цього дня (FILTER з «дані»). Рядки з приміткою підсвічені. |
| `Продуктивність — дні` (700002) | Один рядок на день: підсумки, залишок на розміщення. Приховані N–P: id листа Gmail, рядок початку в «дані», **P1 = стан (JSON)**. |
| `Продуктивність (дані)` (700003) | Один рядок на день+логін, дні по порядку. |

Поля беруться тільки зі звіту: Pezzi → «Шт. всього», Ore → «Години (за LEA)» (не табель),
Missioni → «Місії», Prelievo / Stoccaggio / Correzione stock → підготовка / розміщення /
коригування (у найстаріших і недільних звітах цієї таблиці немає — тоді примітка).
Позначки: більше 12 год за день, 0 год.

## Щоденне оновлення (хмарне заплановане завдання)

1. Gmail: `from:yurii.david has:attachment newer_than:4d`; кожне вкладення
   (`download_gmail_attachment`, attachmentIndex 0) зберегти як `raw/<id листа>.html`.
2. Прочитати `'Продуктивність — дні'!P1` у файл стану.
3. `python3 -m atlas.productivity plan --raw raw --state state.txt --out plan.json`
4. Виконати `clears` (batch_clear_values), потім кожен `writes` (update_values) **в тому порядку**,
   останнім записується P1.
5. Записати відповіді `[{"range", "updatedCells"}]` у result.json і
   `python3 -m atlas.productivity check --plan plan.json --result result.json` → `OK`.

Без дублів: пізніший звіт за той самий день (більший id листа) замінює день; перезапис іде
з першого зміненого дня до кінця. Дні, старші за вікно стану (21 день), пропускаються.
