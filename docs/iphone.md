# Atlas на iPhone: команда «Atlas»

Команда (застосунок «Команди» / Shortcuts) записує голос, надсилає текст на сервер Atlas
і показує, що Atlas записав. Підписані файли команд можна зробити лише на iPhone,
тому команду збирають один раз вручну (≈5 хвилин). Назви дій подано українською та англійською.

Потрібно: адреса `https://…/ingest` і токен (їх друкує `install.sh`).

1. «Команди» → «+» → назва **Atlas**.
2. Дія **Диктувати текст** (Dictate Text). Мова: українська. «Зупинити прослуховування»: після паузи.
3. Дія **Поточна дата** (Current Date) → **Форматувати дату** (Format Date), формат
   «Власний» `yyyyMMddHHmmssSSS`.
4. Дія **Випадкове число** (Random Number) від 100000 до 999999.
5. Дія **Текст** (Text): `iphone-` + Форматована дата + `-` + Випадкове число.
   Це унікальний номер повідомлення: якщо запит повториться, сервер не створить дубль.
6. Дія **Отримати вміст URL** (Get Contents of URL):
   - URL: `https://<адреса>/ingest`
   - Метод: POST
   - Заголовки: `Authorization` = `Bearer <токен>`
   - Тіло запиту: JSON; поля `text` = Диктований текст, `id` = Текст з кроку 5.
7. Дія **Отримати значення словника** (Get Dictionary Value): ключ `reply`.
8. Дія **Показати результат** (Show Result) або **Показати сповіщення** (Show Notification).

Запуск:
- **Кнопка дії** iPhone 16: Параметри → Кнопка дії → Команда → Atlas.
- Siri: «Привіт, Siri, Atlas».
- Віджет на екрані «Додому».

Якщо сервер не відповів (немає мережі), команда покаже помилку, і повідомлення не збережеться —
тоді треба повторити. Якщо сервер прийняв, але Claude недоступний, відповідь буде
«Зберіг повідомлення… оброблю пізніше»: текст уже в базі.

Перевірка без iPhone (з будь-якого комп'ютера):

```
curl -s https://<адреса>/ingest -H "Authorization: Bearer <токен>" \
  -H "Content-Type: application/json" -d '{"text":"Завтра звільнити зону 2O 06","id":"test-1"}'
```
